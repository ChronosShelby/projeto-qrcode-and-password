# 🔐 QR Code & Password Generator

Aplicação de linha de comando (CLI) desenvolvida em **Node.js** para geração de **QR Codes** e **senhas aleatórias personalizadas**.

Projeto desenvolvido para praticar conceitos de **JavaScript, Node.js, modularização, variáveis de ambiente e integração com bibliotecas externas**.

---

## 🚀 Funcionalidades

* 📱 Geração de QR Codes diretamente pelo terminal
* 🔑 Geração de senhas aleatórias
* ⚙️ Configuração do tamanho e dos caracteres da senha através de variáveis de ambiente
* 💻 Interface interativa via terminal

---

## 🛠️ Tecnologias

* **Node.js**
* **JavaScript**
* **NPM**
* **Prompt**
* **Chalk**
* **QRCode Terminal**
* **Dotenv**

---

## 💻 Como funciona

Ao iniciar a aplicação, escolha uma das opções disponíveis:

```text
1 - QR Code
2 - Password
```

### QR Code

Informe o link desejado e a aplicação irá gerar o QR Code diretamente no terminal.

### Password

A aplicação gera uma senha aleatória utilizando o tamanho e os tipos de caracteres definidos no `.env`.

---

## 🎯 Objetivo

Projeto desenvolvido para praticar **Node.js e JavaScript** através da criação de uma aplicação CLI modular e funcional.
